# Stage 19 推荐评测结果

2026-11-18。[评测说明](../recommendation-evaluation.md)

## 数据与比较

五个招聘主体的 30 个官网岗位覆盖 AI 应用、后端、视觉及相邻职能。六组合成求职条件共形成 180 个候选－岗位对。首次排名前冻结了输入、标签和 80 个应用源文件，并在项目内交叉复核了标签。两个方案使用同一有限技能词表，推荐方案额外执行资格和方向筛选，评测未调用模型。

| 指标 | 简单技能匹配 | 当前推荐 |
| --- | ---: | ---: |
| 六档案前五名中值得核对的岗位 | 8/30 | 12/30 |
| 固定分母 P@5 | 0.267 | 0.400 |
| nDCG@5 宏平均 | 0.373 | 0.513 |
| 前五名明确方向或资格错误 | 21/30 | 16/30 |
| 完整保留集合中的相关岗位误排除 | 0/30 | 4/30 |

## 错误与局限

- 推荐方案改善了总体前五相关性，仍有 16/30 个位置出现明确错误，另有 4/30 个相关候选对因方向被排除。后端在校档案由 1/5 提升到 4/5，后端经验档案由 2/5 降到 1/5，视觉在校档案均为 0/5。
- 整体资格一致 130/180。106 个明确不符中识别 56 个，50 个降为待确认，74 个待确认均保持。学历、在读状态和毕业届次需分别抽取后组合，明确阻断不应被通用条款掩盖。样本没有总体符合标签。
- 排他性标题判断丢失了正文中可同时支持多个方向的交付职责。资格证据也曾把团队经历归到候选人身上。技能任选表达和有限词表继续影响分类。
- 目的性采样中，前三个招聘主体占 28/30，同一招聘系统模板占 18/30。标签由 AI 辅助并经项目内复核，尚无独立真人验证。岗位覆盖和采集时点限制了结果可外推的范围。

完整离线回归通过 1,626 项，冻结输入的重复评测结果一致。逐岗位证据、原始语料和详细验收保留在项目本地。
