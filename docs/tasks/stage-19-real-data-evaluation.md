# Stage 19：真实岗位与独立推荐评测

## 目标与实施边界

先补足 AI 应用开发、后端开发、计算机视觉的真实来源岗位，再在新收集、未用于调规则的数据上，对比简单技能匹配与当前 Stage 18 推荐。验收看数据可追溯、比较公平、结果可复跑和错误解释完整，不预设新版一定更好。

本任务在实现前制定。保留 Stage 14–18 工作区及原岗位记录；不调用付费模型或 embedding，不修改推荐规则以迎合测试集，不自动投递。官网可读取不等于仍可投；未明确核实时状态保持 unknown。独立指新来源快照和先标注后运行的留出评测；AI 辅助标注、同一项目内复核不冒称独立真人或用户研究。

## 开发任务与验收标准

| 编号 | 开发任务 | 验收标准 |
| --- | --- | --- |
| R1 | 冻结比较协议和当前规则 | 首次评测前记录生产匹配、方向、资格、去重与排序相关代码的 SHA-256。固定 baseline/current 定义、K=5、标注准则和合成候选档案；随后不依据评测结果调规则。 |
| R2 | 分层收集真实官网岗位 | 新增至少 30 个独立岗位，三个方向各至少 8 个、至少 3 家公司；每条有真实官网详情 URL、来源 ID（如可获得）、公司、城市、职责要求原文、采集/观察时间、获取方式和内容指纹。附公司/方向/招聘类型分布、不可访问与采样偏差；不得用改写示例补数。原有 OPPO 数据不计入新增留出集。 |
| R3 | 导入安全与可重复性 | 复用手动导入工作流；导入前备份本地 SQLite，保留原 17 条记录。先在隔离库验证新增与重复导入；重复导入不新增，原 ID 和正文不被其他岗位覆盖。hash 路由 URL 的不同岗位身份需保持区分；如必须修复身份规则，需兼容既有键并验证。 |
| R4 | 独立标注与冻结数据 | 至少 6 个合成档案，覆盖三方向及不同技能/学历/经验/城市条件；对评测范围内每一候选-岗位对给出 0–3 级相关性、方向、五维资格三态、依据与理由。标注不调用生产推荐/提取器，不读取排名；至少抽查每方向和所有明确资格阻断。首次运行前冻结数据/档案/金标哈希；后续修订保留版本及原因。 |
| R5 | 公平的两组对照 | 两组使用同一冻结快照、稳定编号、同样样例隔离及跨来源分组。简单技能组复用现有技能提取/覆盖率，按覆盖率、匹配数、ID排序，不使用五维资格和目标方向过滤；当前组调用生产 RecommendationService。说明该比较测量整套过滤+排序收益，不将收益归因于单一算法或 LLM。 |
| R6 | 指标、空结果与失败分析 | 输出固定分母 P@5、返回数/覆盖、nDCG@5、Top5 明确方向或资格不符、可投岗位误排除以及资格三态一致性。无相关岗位的指标明确 N/A；少返回不能提高固定分母指标。误排除对完整保留集合计算，不将 Top5 截断误当过滤。报告分子/分母、每档案结果、两组排名和正反案例，不只报汇总提升。 |
| R7 | 离线工具与数据校验 | 提供无需网络/密钥/数据库写入的 CLI，生成 JSON 与可读 Markdown 报告；拒绝重复ID、标签缺失、越界引用、不在冻结官网主机清单的来源、哈希不符、错误枚举。离线校验不声称确认网页现状。相同输入的指标和排名稳定；时刻信息不影响结果。 |
| R8 | 验证、说明与交付 | 有指标手算案例、空结果/零相关/少返回/错误过滤测试、真实数据完整性和导入重复性验证。运行受影响测试及现有离线评测门禁；记录实际执行结果。文档交代标注者身份、样本局限和未覆盖情况；更新当前项目快照和使用入口，不冒称生产效果或真人满意度。 |

## 标注与结果解释

- 五维资格只评价毕业届次、学历及取得状态、正式经验、城市、实习时长；未说明、复杂条件或优先项不能臆定为硬性不符。
- 相关性分级：0=明确无关或不可投；1=方向/关键能力证据不足、仅弱相关；2=方向相关且值得进一步核对；3=方向及核心能力证据充分且无已知资格阻断。具体准则随档案一同冻结。
- 相关性阈值、unknown 如何计入以及招聘状态时效在报告中明示。“值得核对”不等于符合所有要求，更不等于录用概率。
- 如当前规则在新数据上漏掉岗位或无法解释表达，保留错误作为下一阶段开发依据。本阶段不通过修改金标或规则制造提升。
- 首版是小样本、AI 辅助标注的离线留出评测；需要后续真人复核与更多公司/时间切片才能外推。

### 结果边界

本批为目的性小样本和AI辅助盲标，未有独立真人或用户行为验证。三家公司占28/30，18条共用招聘系统模板；没有硕博在读档案、没有整体五维全符合金标。视觉两组各仅2个正相关岗位，P@5理论上限0.4，六意图供给上限均值0.667。后续修复可使用这些错误作开发案例，但须另收未见岗位验证，不再把修过的本批称为新独立测试。
